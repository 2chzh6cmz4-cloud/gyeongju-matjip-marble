# 경주 맛집마블 V3.6.1

변경사항
- START 도착 시 상세 팝업 없음
- 구내식당 도착 시 상세 팝업 없음
- START를 직접 눌러도 팝업 없음
- 구내식당을 직접 눌러도 팝업 없음
- 주사위 이동으로 START에 정확히 도착하면 주사위 1회 자동 추가
- START를 단순히 지나가는 경우에는 보너스 없음
- 행운카드 효과로 START에 강제 이동한 경우에도 보너스 1회
- 더블과 START 도착이 동시에 발생하면 각각의 보너스를 모두 인정
- 기존 80칸 / 행운카드 4칸 / 행운카드 10종 / 지도 링크 / 미니 컨트롤바 유지

행운카드
- 전체 80칸 중 4칸(칸 비율 5%)
- 행운카드 칸에 정확히 도착하면 100% 발동
- 카드 10종은 현재 동일확률(각 10%)

GitHub에서는 index.html과 sw.js만 교체하면 됩니다.
