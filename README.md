# 경주 맛집마블 V3.4.1

미니 컨트롤바 반응성 수정
- 미니바 표시 애니메이션 중 첫 탭이 먹지 않는 현상 제거
- 표시되는 순간 바로 pointer/touch 입력 가능
- iOS Safari용 touch-action: manipulation 적용
- 미니 주사위 버튼은 원래 버튼의 click()을 거치지 않고 animateRoll() 직접 실행
- 미니 랜덤 버튼도 랜덤 선택 함수를 직접 실행
- 원래 컨트롤이 상단 아래로 들어가기 시작하면 미니바가 더 빠르게 표시
- 주사위 굴리는 중에는 미니버튼 즉시 비활성화, 종료 즉시 복구

기존 기능 유지
- 주사위 2개
- 더블 시 한 번 더
- 76칸 이동 경로
- 우상단 특수칸 포함
- 가로/세로 자동 화면 추적

GitHub에서는 index.html과 sw.js만 교체하면 됩니다.
